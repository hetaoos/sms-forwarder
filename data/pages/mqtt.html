MQTT 设置

连接标准 MQTT Broker，把短信 / SIM / 启动 / 上线 / 日志以 JSON 形式实时推送出去，并通过命令主题接收远程控制（发短信、发 AT、重启等）。

功能启用

关闭后不再连接 Broker，也不会发布任何事件（已保存的连接 / 主题配置保留）。

Broker 连接 · 尚未配置

⚠

事件通知类型

勾选的事件会以 JSON 报文发布到 <前缀>/<设备ID>/<类型>（如 smsf/abcd1234ef56/sms）。

主题与命令说明

主题 / 命令说明
<前缀>/<设备ID>/sms收到短信事件（from / message / time / modem）
<前缀>/<设备ID>/simSIM 插拔事件（port / ready）
<前缀>/<设备ID>/boot设备启动完成（开机首次连上发布一次）
<前缀>/<设备ID>/online设备（重新）上线通知
<前缀>/<设备ID>/log运行日志实时推送（限流 20 条/秒）
<前缀>/<设备ID>/status设备状态（online/offline 遗嘱，retained）
<前缀>/<设备ID>/command订阅：发送 JSON 命令（见下）
<前缀>/<设备ID>/command/response命令执行结果回执
支持的命令：send_sms(phone,content,可选 modem) · send_at(cmd,可选 modem/timeout) · restart · reinit(modem) · info · help。所有命令均需通过 command 主题下发 JSON，例如：{"action":"send_sms","phone":"10086","content":"YE"}
