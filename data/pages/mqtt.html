MQTT 推送

连接标准 MQTT Broker（esp-mqtt 组件，无需额外库），事件以 JSON 发布，并支持订阅命令主题做远程控制。配置保存到 NVS，重启后仍有效

MQTT Broker

已停用：短信 / SIM / 启动 / 上线 / 日志事件都不会发布，命令订阅停止； 已保存的服务器、账号与通知类型保留，重新开启后立即恢复。
事件发布到 <前缀>/<设备ID>/<类型>（sms / sim / boot / online / log / status）；
启用命令订阅后，可向 <前缀>/<设备ID>/command 发送 JSON 命令 （send_sms / send_at / restart / reinit / info / help）。
TLS 仅加密、不校验证书；加密端口通常为 8883，明文端口（如 1883）请勿勾选 TLS， 否则握手失败（日志报 tls_err=0x8004 / 0x800B）。连接失败多为地址/端口/网络问题，先确认设备能访问该 Broker。

事件通知类型

勾选的事件会各自发布一条 JSON 报文；关闭后不影响短信存储、SSE 与其它功能。
